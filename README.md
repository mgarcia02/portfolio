Este es mi portfolio personal, desarrollado con **React + TypeScript + Vite**. Su objetivo principal es servir como **expositor de proyectos**, mostrando de forma clara y visual los trabajos que he realizado, destacando las tecnologías utilizadas y enlazando al código fuente.

🔗 **Ver portfolio online:** [https://mgarcia02.github.io/portfolio/](https://mgarcia02.github.io/portfolio/)

## 🚀 Tecnologías principales
- [React](https://reactjs.org/) (v19)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- CSS Modules

## 📂 Estructura del proyecto
```
src/
├─ App.tsx      # Componente raíz con rutas y layout principal
├─ main.tsx     # Punto de entrada
├─ assets/      # Imágenes, fuentes y recursos estáticos
├─ components/  # Componentes reutilizables (ProjectCard, Navbar, etc.)
├─ context/     # Contextos de React (Tema)
├─ data/        # Info proyectos u otros datos
├─ hooks/       # Custom hooks (useScrollReveal, useCustomCursor)
├─ styles/      # Estilos globales
└─ types/       # Definiciones de tipos TypeScript globales
```

## 🛠️ Instalación
Clona el repositorio y ejecuta:

```bash
npm install
npm run dev
```

## 🎯 Objetivo
Construir un portfolio modular, profesional y escalable que refleje mi evolución como desarrollador Full Stack, con foco en automatización, IA y buenas prácticas.
